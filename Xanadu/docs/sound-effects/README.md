# Sound effects library (T7)
Folders: Steps, Doors, Water, Weather (thunder, rain, wind), Impacts, Ambience, Foley, Horror.
Each file: `<category>/<name> - <source>.wav|mp3`. Keep a `SOURCES.md` line per download: name, URL, licence (must allow monetized use), date.
Nothing is downloaded without the user's OK first (filename, source, size, licence).
